# Momo

[English](README.md) | [日本語](README.ja.md)

**Momo 是一个住在 Obsidian 里的轻量记录插件。**

## 它能帮你做什么

### ✍️ 随手就记

- 侧边栏常驻一个「写点什么」发布框：写几个字发出去，自动在 Obsidian 编辑器里打开接着写。
- 用的还是 Obsidian 原生的编辑器——熟悉的加粗、列表、图片，一个都没变。

### 🗂 整整齐齐

- **标签**：正文里写 `#标签` 就行；支持 `#父/子` 多级，选父标签自动带上所有子标签。
- **批量整理**：多选几条笔记，一次加标签、去标签、加地点、移除地点。
- **标签管理**：侧栏标签上右键，就能改名、合并、置顶常用标签。
- **置顶笔记**：重要的那条钉在列表最上面，翻旧笔记时一眼先看到。

### 🔍 找得回来

- **搜索**：顶部搜索框，命中的词在卡片里高亮。
- **筛选**：标签、地点、日期可以同时选，条件在筛选条里各是一颗小胶囊，点 ✕ 就撤掉。
- **侧栏速览**：笔记数、标签数、记录天数，打开就看见。

### 📍 给记忆安个家（地点）

- 给笔记标上地点（如「北京」），侧栏「全部地点」按 大洲 → 国家 → 地点 收成一棵树，点哪层看哪层。
- 也能切成「按地点分组」的浏览方式，或打开**星球视图**：记过的地点落在一颗缓缓旋转的地球上，点一个光点，就是那个地方写下的字。
- 内置世界主要城市名册，常见城市直接写名字就能认。

### 💫 温故知新（回顾）

- 五种翻旧账的方式：**随机**、**一周未看**、**一月未看**、**很久没看**、**往年今日**。
- 先筛好标签再进回顾，就是「只翻这个标签下的旧笔记」。
- 一批看完点「再抽一批」，旧笔记常看常新。

### 📊 看见自己的习惯（统计）

- **活跃度热力图**：侧栏最近几个月的记录密度，颜色越深那天写得越多；点一下某天，直接看那天写了什么。统计页里还有整年版，可以翻年份。
- **统计页**：从「写了多少」到「什么时候最有劲」「标签用得怎么样」「内容有多长」，一眼看清自己的记录习惯。
- 统计页里几乎所有数字都能点——点一下，带着对应的筛选跳回笔记列表。

### 🗑 删错了也不怕

- 删除的笔记先住进「回收站」，随时可以恢复；确认不要了再彻底清除。
- 卸载插件也不会动你的任何文件——所有记录都是普普通通的笔记，一直在你自己的库里。

## 适合谁用

- **随手记碎片的人**：灵感、待办、一闪而过的念头，不想新建文件，敲几句就发。
- **写日记 / 手账的人**：按日期流回看自己的每一天，热力图就是坚持的痕迹。
- **旅行 / 生活记录者**：给笔记标地点，日后按城市、按国家翻旧账，还有一颗星球帮你回望。
- **阅读 / 观影 / 育儿记录者**：用标签分门别类，用「回顾」让记过的东西真正被再看一遍。
- **在意数据主权的人**：不联网、无账号、无遥测，笔记永远只是你自己的文件。

## 快速上手

### 日常三步

1. **记**：侧边栏发布框写点什么，回车；
2. **理**：给卡片加个标签、标个地点（都可以多选批量做）；
3. **翻**：闲时点「随机回顾」重逢旧笔记，或去「统计」看看这一年的自己。

### 几个顺手小技巧

- **补记**：昨晚忘了记？在命令面板搜「补记到过去…」，选一天补上；对称地还有「写到未来…」。
- **存为 Momo**：在 Obsidian 任何笔记里选中一段文字，右键「存为 Momo」，那段话就成了一条独立记录。
- **快速回家**：点左上角的品牌图标或名字，立刻回到「全部笔记」最顶上。
- **整理标签**：在侧栏标签上右键，可以改名、合并重名的标签，或把常用标签置顶。
- **按需露脸**：设置 → 面板与侧栏 →「视图」里，可以决定顶栏出现哪几档视图、按什么顺序排。

## 常见问题

**我的数据存在哪儿？**
全部在你自己的笔记库里，就是一篇篇普通的笔记文件，用 Obsidian 本身就能打开、编辑、同步。插件只另外记一本小账（回收站里有哪些、你的界面偏好），仅此而已。

**卸载插件会丢东西吗？**
不会。你的笔记一个文件都不会被动过。

**需要联网或注册账号吗？**
完全不需要。没有服务器、没有用户系统，所有功能都在本地完成。
