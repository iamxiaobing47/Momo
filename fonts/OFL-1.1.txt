# 内置开源字体（fonts/）· 来源与授权

本目录的四套字体随 Momo 插件分发（构建时整目录同步进各 vault 的插件目录），
运行时经 app:// 资源 URL 注入 @font-face（src/views/fontFaces.ts），目录清单
与 @font-face 家族名在 src/momo/types/prefs.ts 的 BUNDLED_FONTS。

全部四套均以 **SIL Open Font License 1.1**（下附全文）授权，可自由随插件
再分发、嵌入与使用。各家版权声明如下（授权全文里的 Reserved Font Name
条款按各家原始声明执行；本插件以 @font-face 的「Momo …」家族名引用，
不改动、不重命名字体文件本体）：

| 文件 | 字体 | 版权 | 来源 |
|---|---|---|---|
| LXGWWenKaiLite-Regular.ttf | 霞鹜文楷（Lite）Regular | Copyright 2020-2024 lxgw | https://github.com/lxgw/LxgwWenKai-Lite（v1.522） |
| LXGWWenKaiLite-Medium.ttf | 霞鹜文楷（Lite）Medium | 同上 | 同上 |
| NotoSansSC[wght].ttf | 思源黑体 Noto Sans SC（可变字重） | Copyright 2014-2021 Adobe, with Reserved Font Name 'Source' | https://github.com/google/fonts/tree/main/ofl/notosanssc |
| NotoSerifSC[wght].ttf | 思源宋体 Noto Serif SC（可变字重） | 同上 | https://github.com/google/fonts/tree/main/ofl/notoserifsc |
| JetBrainsMono[wght].ttf | JetBrains Mono（可变字重） | Copyright 2020 The JetBrains Mono Project Authors | https://github.com/google/fonts/tree/main/ofl/jetbrainsmono |

换字体 / 加字重时：文件放进本目录 → 上表加一行 → BUNDLED_FONTS 加一条 →
i18n 三语言的 copy.meta.fontName 补名字（见 prefs.ts 顶部注释的三步）→
scripts/fetch-fonts.mjs 的 FILES 补一条（urls + bytes + sha256；两个值用
`sha256sum fonts/<文件>` 与 `stat -c %s fonts/<文件>` 得出，工序见该脚本文件头）。
