# Momo

[简体中文](README.zh.md) | [English](README.md)

**Momo はカード式ノートプラグインです。**

ファイル名・タイトル・保存場所・書式の管理は Momo が引き受け、残るのは記録そのものだけ。ノートはタグと地点で整理し、さまざまなビューとふりかえりで、いちばん楽な姿勢のまま、過去の自分と再会できます。

その理念はひと言だけ：

> **あなたの注意力を守り、ひいてはあなたの感情を守る。そしてあなた自身を、レバレッジがもっとも効く場所に置く。**

Momo の中を歩いているあなたは、何百、何千、何万もの過去の声と言葉を交わしています。Momo にいるかぎり、あなたは孤独ではありません。記したすべてのノートは、過去の自分から、しばらくのあいだ一緒に歩いた人や出来事から借りてきたもの。未来の自分へ、そしてひょっとしたらそれを読む誰かへの贈り物でもあります。

Momo は生まれた初日から、あなたのために引き算をしています：

- **ファイル名・タイトル・保存場所・書式を管理しなくていい。** 投稿ボックスに数行書いてエンター、
  それだけでもう一件のノート。ファイルの名前・置き場所・見た目は、すべて Momo が面倒を見ます。
- **タグと地点でノートに印をつける。** `#タグ` や「北京」といった小さな印が、整理のすべてです。
- **ランダムふりかえりは、過去の自分との散歩。** 予定も努力もいりません。静かな午後、一枚の古いノートがふっと目の前に舞い降りるだけ。
- **いちばん楽な読み方ができるビューが揃っている。** リスト・焦点・地球・地点——見たいように見ればいい。

## どんな見た目か

- **リストビュー**：すべてのノートがカードのように並ぶ。ざっと読む、絞る、まとめて整理する、この画面だけで全部できます。

![alt text](assets/image-1.png)

- **焦点ビュー**：一度に向き合うのは一枚のノートだけ。上下のカードは背景に溶け、静かに読めます。

  ![alt text](assets/image-2.png)

- **地球ビュー**：記録した地点がゆっくり回る地球に並ぶ。光点をタップすれば、その場所に書いた文字が読めます。

  ![alt text](assets/image-3.png)

- **地点ビュー**：大陸 → 国 → 地点 の木にまとまり、見たい階層をクリックするだけ。

  ![alt text](assets/image-4.png)

- **豊富な配色**：霧藍・苔緑・墨夜から、気に入った一つを選べばいい。

  ![alt text](assets/image-5.png)

## よくある質問

**データはどこにありますか？**
すべてあなたのライブラリの中、ありふれたノートファイルとして。Obsidian 本体で開く・編集する・同期する、すべてできます。プラグインが別に記録するのは小さな台帳（ゴミ箱の中身と、あなたの表示の好み）だけです。

**アンインストールすると何か失われますか？**
いいえ。ノートのファイルはひとつも触られません。
