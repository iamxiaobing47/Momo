# Momo

[简体中文](README.zh.md) | [English](README.md)

**Momo は Obsidian の中で動く、軽量な記録プラグインです。**

## できること

### ✍️ さっと書ける

- サイドバーに「何か書く」投稿ボックスが常駐。数文字書いて送るだけで、Obsidian エディターが開いて続きが書けます。
- 使うのは Obsidian 純正のエディター——いつもの太字、リスト、画像、そのままです。

### 🗂 しっかり整理できる

- **タグ**：本文に `#タグ` と書くだけ。`#親/子` の多階層にも対応していて、親タグを選べば子タグが全部まとって付いてきます。
- **一括整理**：複数のノートを選んで、タグの追加・解除、地点の追加・解除を一度にできます。
- **タグの管理**：サイドバーのタグを右クリックすれば、名前変更、統合、よく使うタグのピン留めができます。
- **ピン留めノート**：大切な1件をリストのいちばん上に留めます。古いノートをめくるとき、まず目に入ります。

### 🔍 あとから見つかる

- **検索**：上部の検索枠。ヒットした語はカードの中でハイライトされます。
- **絞り込み**：タグ・地点・日付を同時に選べます。条件は絞り込みバーに小さなカプセルとして並び、✕ で外せます。
- **サイドバーのサマリー**：ノート数・タグ数・記録日数。開いた瞬間に目に入ります。

### 📍 思い出に居場所を（地点）

- ノートに地点（「北京」など）を付けると、サイドバーの「すべての地点」が 大陸 → 国 → 地点 の木にまとまります。見たい階層をクリックするだけ。
- 「地点でグループ」の閲覧に切り替えたり、**地球ビュー**を開いたり：記録した地点がゆっくり回る地球に並び、光点をタップすれば、その場所に書いた文字が読めます。
- 世界の主要都市名簿が内蔵されているので、よくある都市名は書くだけで認識されます。

### 💫 昔をめくる（ふりかえり）

- 古いノートのめくり方は5通り：**ランダム**（どれでも）、**1週間未見**（1週間触っていない）、**1か月未見**（1か月触っていない）、**長らく未見**（久しぶり）、**往年の今日**（昔の同じ日）。
- 先にタグで絞ってからふりかえりに入れば、「このタグの古いノートだけ」をめくれます。
- 1バッチ見終わったら「次のバッチを引く」。古いノートが何度でも新鮮に。

### 📊 自分の習慣が見える（統計）

- **アクティビティヒートマップ**：サイドバーに直近数か月の記録密度。その日たくさん書くほど色が濃くなり、日付をクリックすればその日に書いたものがそのまま読めます。統計ページには年全体版があり、年をめくれます。
- **統計ページ**：「どれだけ書いたか」から「いつがいちばん書けるか」「タグの使いぐあい」「内容の長さ」まで、自分の記録の癖がひと目で。
- 統計ページの数字はほとんどがクリックできます——押すと、対応する絞り込みを携えてノートリストに戻れます。

### 🗑 消しても安心

- 消したノートはまず「ゴミ箱」へ。いつでも復元でき、本当に不要になってから完全削除。
- プラグインをアンインストールしても、あなたのファイルはひとつも動きません——すべての記録はありふれたノートのまま、あなたのライブラリにあります。

## こんな人におすすめ

- **思いつきを残したい人**：アイデア、ToDo、ふと浮かんだ考え。ファイルを新規作成しなくても、数行書いて送るだけ。
- **日記・手帳をつける人**：日付の流れで毎日を振りかえり、ヒートマップは継続の跡。
- **旅行・生活の記録者**：ノートに地点を付けておけば、あとから都市別・国別に古い日々をめくれます。振りかえるための地球も付いてきます。
- **読書・映画・育児の記録者**：タグで分類し、「ふりかえり」で書いたものが本当にもう一度読まれるように。
- **データの自主権を大切にする人**：ネット不要、アカウント不要、テレメトリなし。ノートはいつまでもあなただけのファイル。

## すぐに始める

### いつもの3ステップ

1. **書く**：サイドバーの投稿ボックスに何か書いて、Enter；
2. **整える**：カードにタグを付け、地点を付ける（どちらも複数選んで一括できます）；
3. **振りかえる**：暇なときに「ランダムふりかえり」で古いノートと再会、または「統計」で今年の自分を眺める。

### あると便利な小技

- **補記**：昨晩書き忘れた？コマンドパレットで「過去の日に補記…」を検索して日付を選べば補えます。鏡のコマンド「未来の日に書いておく…」もあります。
- **Momoに保存**：Obsidian の任意のノートで文字を選び、右クリック「Momoに保存」。その一節が独立した1件になります。
- **一瞬でホーム**：左上のブランドアイコンか名前をクリックすれば、「すべてのノート」のいちばん上にすぐ戻れます。
- **タグを整える**：サイドバーのタグを右クリックで、名前変更・重複の統合・よく使うタグのピン留め。
- **ビューは選んで置く**：設定 → パネルとサイドバー →「ビュー」で、トップバーにどのビューをどの順で並べるか決められます。

## よくある質問

**データはどこにありますか？**
すべてあなたのライブラリの中、ありふれたノートファイルとして。Obsidian 本体で開く・編集する・同期する、すべてできます。プラグインが別に記録するのは小さな台帳（ゴミ箱の中身と、あなたの表示の好み）だけです。

**アンインストールすると何か失われますか？**
いいえ。ノートのファイルはひとつも触られません。

**ネット接続やアカウント登録は必要ですか？**
まったく不要です。サーバーもユーザーシステムもなく、すべての機能はローカルで動きます。

## 権限とプライバシー

Momo はローカル優先です：アカウントなし、テレメトリなし、アップロードなし。
コミュニティプラグインの審査で指摘される三点と、それぞれの用途：

- **保管庫の列挙**（`vault.getMarkdownFiles`）：保管庫のノートをカードとして索引すること
  がこのプラグインの機能そのものです（タグ・場所・ヒートマップ・振り返りはすべてその索引を
  読みます）。パスはあなたのマシンのメモリ上にとどまります。
- **クリップボード**：書き込みのみ。しかもユーザー操作のときだけ——カードのコピーボタンを
  押すか、パネルで Ctrl/Cmd+C を押したときで、書き込まれるのも選択したテキストだけです
  （ノートへの画像貼り付けは Obsidian 自身のペーストイベントです）。バックグラウンドで
  読み取ることはなく、これらの操作以外で触れることもありません。
- **ネットワーク**：あなたが押したときだけ発生する任意ダウンロードが 2 つあるだけです。
  3D 地球のテクスチャはインストールパッケージに含まれません（Obsidian のインストーラが
  取得するのは `main.js` / `manifest.json` / `styles.css` のみ）——設定の
  **「アセットパックをダウンロード」**ボタンが本リポジトリの release から取得します。
  オープンソース字体パック（霞鶩文楷 / Noto Sans SC / Noto Serif SC / JetBrains Mono、
  SIL OFL）も同じ道筋で：**設定 → 界面外観**の字体カードで、未ダウンロードのタイルを
  押すと文件サイズを報べる確認框が出て、確めてから取得します。どちらも取らなくても动きます
  ——地球は canvas フォールバック、字体は Obsidian 自身のものに戻ります。
